
# 📚 Online Book Store Management System

A robust, enterprise-inspired desktop/web simulation system constructed using  Java. The application models catalog parsing, shopping cart dynamics, user accounts, and checkout transactions cleanly.

---

## 💡 Key Structural Features
- **Object-Oriented Design:** Implements clean architectural design patterns using encapsulation, inheritance, and polymorphism.
- **Inventory Engine:** Manages book records dynamically including structural filtering by genre, author, price, and availability.
- **User Transaction Matrix:** Features robust logic handling shopping cart additions, price computations, and order summaries.

---

## 🛠️ Tech Stack & Concepts
- **Language:** Java (JDK 17+)
- **Concepts:** Object-Oriented Programming (OOP), Data Structures, File I/O
- **Database/Storage:** JDBC / MySQL (or Collections framework if kept in memory)
